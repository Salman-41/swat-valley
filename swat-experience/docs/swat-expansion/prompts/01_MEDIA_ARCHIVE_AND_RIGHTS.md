Build an accessible searchable media archive with filters, usable lightbox, pagination, source card, credit links, alt text, and keyboard support. Tie media into existing pages thoughtfully, not generic galleries.

Create a source-rights audit test that fails when displayed assets lack valid license/creator/URL (with intentional exception for original project graphics), and an editorial gap list for craft/people/audio not yet cleared.
