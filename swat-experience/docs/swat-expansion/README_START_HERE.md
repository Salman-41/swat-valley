# SWAT — Materials & Functional Expansion (October 22, 2026)

This pack is for an **existing** SWAT website repository. It does not replace its implementation, recreate its design, or claim access to the user's current code.

## How to use
1. Add this research pack to the existing repository as `docs/swat-expansion/`.
2. Give the coding agent `prompts/00_INSPECT_CURRENT_SITE.md` and require actual repo inspection before edits.
3. Proceed through prompts 01–07 one at a time, same repository and tracked commits. Never run all phases in parallel.
4. After each phase, demand code, live browser testing, screenshots, source/rights records and a gap report.
5. If the earlier SWAT Figma/Codex package is available, it is background reference only. The actual current deployed repo is the truth.

## Key assets
- `RESEARCH_SOURCES_AND_LICENSES.md`: research bibliography and rights notes.
- `data/SOURCE_REGISTRY_SEED.json`: machine-readable seeds, deliberately marking `actual_download_verified=false`.
- `EDITORIAL_COVERAGE_PLAN.md`: page/content/feature inventory and completion definition.
